# Unique Value Proposition

Це не просто книга.
Це простір для ваших спільних моментів, слів і почуттів, які хочеться зберегти.
Книга допомагає сказати найважливіше — щиро, просто і без пафосу.
Підійде для подарунка близькій людині або для себе.

## Style / Tone / Visual Direction

**Стиль:** теплий, емоційний, сучасний scrapbook / memory book

**Відчуття:** затишок, щирість, легка ностальгія, турбота

**Тон тексту:** мʼякий, підтримуючий, без гендерних форм, без пафосу

**Візуально:**
- папір, нотатки, рамки для фото
- ефект «записника» / «альбому спогадів»
- ручні елементи, стрілки, підкреслення, наліпки
- яскраві, але теплі кольори (синій, жовтий, рожевий, кремовий)

**Ассоціації:** подарунок зі змістом, книга яку заповнюють поступово, про людей і моменти, а не про ідеальність

## Коротко для Hero-блока

**Headline:**
Не просто книга. Про вас.

**Subheadline:**
Про спільні моменти, слова підтримки і те, що хочеться зберегти надовго.

## Почему это идеально ложится на твои макеты

- полностью совпадает с визуалом тетради / коллажа / альбома
- не привязано к полу, статусу, возрасту
- объясняет ценность без продажи в лоб
- Codex по этому описанию сделает мягкий, живой лендинг, а не шаблонный e-commerce
